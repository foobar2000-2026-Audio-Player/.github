# Project Overview

foobar2000 is a lightweight and highly customizable audio player designed for music playback, library management, playlist organization, metadata editing, audio conversion, and advanced audio workflows.

The Windows version supports a wide range of audio formats and can be extended through a large ecosystem of components. Its interface can be customized extensively, allowing users to build simple playback layouts or more advanced music-library workspaces.

As of September 2026, the latest stable Windows release is **foobar2000 2.25.10**, released June 26, 2026. The **2.26** branch is available as a preview build, with a preview released September 22, 2026. ([foobar2000.org](https://www.foobar2000.org/windows?utm_source=chatgpt.com))

# Music Playback & Audio Formats

foobar2000 provides playback support for numerous audio formats through its built-in decoders and optional components.

The player supports features such as gapless playback, ReplayGain, customizable playback queues, playlists, and advanced playback configuration.

Its lightweight architecture makes it suitable for both basic music listening and detailed audio-library workflows.

The Converter component can also be used to convert supported audio files between compatible formats when the required encoder components are available.

---

# Music Library & Playlists

foobar2000 provides tools for organizing large collections of locally stored music.

The Media Library can monitor selected folders and make indexed tracks available for searching and playlist creation.

Users can create multiple playlists, sort tracks using metadata, search collections, and arrange playback queues according to their preferred workflow.

Playlist management can be combined with customizable title formatting to display artist, album, track, codec, bitrate, replay gain, and other information.

---

# Metadata & Tag Editing

foobar2000 includes tools for viewing and editing metadata embedded in supported audio files.

Users can modify tags such as artist, album, title, genre, date, track number, disc number, and other available fields.

Batch tag editing can be used to update metadata across multiple files at once.

The application also supports title formatting, allowing users to create customized ways of displaying track information throughout the interface.

---

# Converter & Audio Processing

The Converter component provides a graphical workflow for converting supported audio files.

Users can select source tracks, choose an available encoder, configure output settings, and define naming and destination rules.

foobar2000 also provides ReplayGain scanning, DSP processing, resampling, channel manipulation, and other audio-processing options through built-in features and components.

The actual processing capabilities depend on the selected components, source format, and output encoder.

# 2026 Updates

The stable Windows release **foobar2000 2.25.10** was released on June 26, 2026. It includes:

* Improved built-in UPnP Media Renderer.
* Gapless playback support for compatible UPnP control applications.
* OpenHome UPnP device discovery.
* TLS 1.3 support for HTTPS connections.
* Ogg/Opus chapter handling fixes.
* Direct2D visualization fixes after GPU driver reinitialization.
